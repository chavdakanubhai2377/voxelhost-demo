# VoxelHost demo

This repository contains a small static demo landing site for a Minecraft hosting service called "VoxelHost". It's a demo and mockup only.

Files included:
- `index.html` — main static page
- `styles.css` — styles
- `logo.svg` — demo logo

How to preview locally

Option A — Open directly
1. Download the repo as ZIP and open `index.html` in your browser.

Option B — Using a tiny static server (recommended)

If you have Node.js installed:

1. Install `serve` (one-time):

   npm install -g serve

2. From the repo directory run:

   serve . -p 8080

3. Open http://localhost:8080 in your browser.

Deploy to Vercel (fast)

1. Go to https://vercel.com and sign in.
2. Click "New Project" → Import Git Repository → select `chavdakanubhai2377/voxelhost-demo`.
3. Accept defaults and deploy. Vercel will build and provide a public URL.

Deploy to Netlify

1. Go to https://app.netlify.com and sign in.
2. Click "Add new site" → "Import from Git" → choose this GitHub repo.
3. Select branch `main`, and deploy.
